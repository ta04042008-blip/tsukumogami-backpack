# 付喪神バックパック（仮）

![Validate Prototype](https://github.com/ta04042008-blip/tsukumogami-backpack/actions/workflows/validate.yml/badge.svg)

和風モダン × 付喪神 × カバン整理ローグライトのプロトタイプです。

ショップで古道具を集め、6×5のカバンに配置して戦います。  
戦闘はオート。プレイヤーは「何を買うか」「どこに置くか」「どの道具を隣り合わせるか」を考えます。

## 現在のコアシステム

- 6×5のグリッド式カバン
- アイテムの配置・回転
- 隣接 / 向きによる強化
- オートバトル
- ショップと所持金
- **道具変化**：特定の道具を上下左右に隣接させると、戦闘後の次ターンに別の道具へ変化
  - 例：槌 + 鏡 → 割れた鏡
  - 単純な上位合成だけではなく、破損・変質・特殊化も起きます
- 変化後の道具をさらに別の道具と反応させる二段階レシピ
- 付喪神化は次段階で実装予定（変化ツリーの先として設計中）

## 遊び方

このリポジトリをダウンロードして `index.html` をブラウザで開けば遊べます。  
静的HTML/CSS/JavaScriptのみで動作し、ビルドは不要です。

### 基本操作

1. ショップから道具を購入
2. 仮置き場の道具を選択
3. カバンのマスをタップして配置（PCではドラッグ&ドロップにも対応）
4. 必要なら「回転」で向きを変更
5. 「戦闘開始」でオートバトル
6. 戦闘終了後、隣接していた対応道具が変化
7. 次のターンで再び整理

対応レシピがある隣接ペアには「変化予定」が表示されます。離せば変化はキャンセルされます。

## プロトタイプの目的

完成版のグラフィックを作る前に、以下が面白いかを検証します。

- 限られたカバンを整理する楽しさ
- 隣接効果と向きを考える楽しさ
- 「この2つを並べたら何になる？」というレシピ発見
- 一見ハズレの変化品を後から強い道具へ育てる体験
- 古道具が付喪神になっていくテーマとの一体感

詳しい仕様は [GAME_DESIGN.md](./GAME_DESIGN.md) を参照してください。
